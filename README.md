# 🧸 Boredom Buster

A cozy little web app that gives you random activities whenever you're bored.

Built using CodeIgniter 4 with a soft beige & butter-yellow aesthetic UI ✨

---

## 📸 Preview

![Boredom Buster Preview](screenshots/Screenshot1.png)

---

## ✨ Current Features

* 🎲 Random activity generator
* 🧸 Cozy aesthetic user interface
* ⚡ Instant activity suggestions
* 🗄️ MySQL database integration
* 📱 Responsive centered layout

---

## 🛠️ Tech Stack

* PHP
* CodeIgniter 4
* MySQL
* JavaScript
* HTML/CSS

---

## 🗄️ Database Setup

Import the SQL file located inside:

database/boredom_db.sql

---

## 🚀 Run Locally

Start the local development server:

php spark serve

Then open:

http://localhost:8080

---

## 💡 About

This project was built as a fun mini-project to practice backend and frontend web development using CodeIgniter 4.
